Intent Classification Flow

Message routing between purchase, support, and upsell flows

Input Sources - Messages & Context
Processing - Classification & Routing
Actions - Response Generation
Persistence - Update & Store
Output - Telegram Delivery

1️⃣ Message Reception

Telegram webhook receives user message, loads user context from memory and database, validates input format and extracts intent keywords.

2️⃣ Intent Classification

Google Gemini AI analyzes message intent with intelligent keyword fallback. Classifies as Purchase, Support, or Upsell based on user intent.

3️⃣ Purchase Flow

Displays product catalog with pricing, enables add-to-cart buttons, processes checkout orders with Stripe payment integration.

4️⃣ Support Flow

Delivers help content, logs support tickets in database, suggests solutions, provides escalation pathways for complex issues.

5️⃣ Upsell Flow

Recommends add-ons based on purchase history and preferences, highlights premium features, suggests upgrade opportunities.

6️⃣ Persistence Layer

Updates user memory cache, logs analytics events, stores order data and complete conversation history to SQLAlchemy database.

7️⃣ Response Delivery

Formats response with Markdown syntax, attaches interactive inline buttons (price, cart, checkout), sends back to Telegram API.

8️⃣ Completion

User receives formatted message with interactive buttons on Telegram. System ready for next user message or callback query interaction.
