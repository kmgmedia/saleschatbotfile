📊 Conversation Analytics

Session metrics, conversion rates, and intent distribution tracking

Data Sources - Events collected
Analytics - Calculations & processing
Metrics - Computed values
Insights - Aggregation layer
Display - Dashboard & decisions

📊 Session Metrics

Tracks overall bot performance and user engagement

  • Total sessions per time period
  • Average session duration
  • Messages per user
  • User retention rate

💰 Conversion Rates

Measures purchase funnel performance

  • Overall conversion rate (%)
  • Funnel stage analysis
  • Drop-off points identification
  • Revenue per user

🎯 Intent Distribution

Analyzes user intent patterns

  • Purchase intent %
  • Support inquiry %
  • Upsell engagement %
  • Bot confusion rate

🏆 Product Analytics

Tracks individual product performance

  • Most viewed products
  • Highest conversion products
  • Average price inquiries
  • Product comparison rates

👤 User Engagement Score

Composite metric for user interaction level

  • 0-100 engagement scale
  • Based on messages & interactions
  • Identifies high-value users
  • Predicts purchase likelihood

📱 Button Analytics

Measures interactive element effectiveness

  • Button click rates
  • Most used actions
  • Cart adds per session
  • Checkout completion %

🎨 Analytics Dashboard Features

📈
Real-time Charts - Live conversion funnel, intent pie chart, product rankings
🔄
Auto-refresh - Dashboard updates every 30 seconds for live monitoring
📅
Time Filters - View metrics for 7, 14, 30, or 90-day periods

Secure Access - Admin API key authentication for data protection
